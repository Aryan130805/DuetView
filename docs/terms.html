2 System Requirements & Network Environment

DuetView requires appropriate hardware and network environments to operate effectively:

  • Windows Host: Windows 10 (64-bit) or Windows 11 with DirectX 11 / DXGI 1.2+ support.
  • Android Client: Android 8.0 (API 26) or higher with H.264 MediaCodec hardware decoding capability.
  • Local Network: Standard Wi-Fi router (5 GHz recommended) or direct USB cable with USB tethering enabled.

DuetView operates entirely peer-to-peer. You are responsible for ensuring your local network firewall permits inbound connections on TCP ports 52025 and 52027, and UDP discovery broadcasts on port 52026.

3 Virtual Display Driver (IddCx)

For Extended Desktop functionality, DuetView includes an optional Indirect Display Driver (IddCx / UMDF 2.x). Installation of this driver requires administrator privileges on Windows. The driver is provided for personal desktop extension purposes.
