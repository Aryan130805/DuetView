02 Intended Use & Functionality

DuetView is designed solely as a personal and professional companion display utility to:

  • Extend your Windows desktop workspace onto a compatible Android device.
  • Mirror your primary Windows display to your Android device with low latency.
  • Deliver touch, mouse, and keyboard input controls from the Android client to your Windows host.

DuetView operates strictly across your private local area network (LAN) or direct USB tethering. It does not route, proxy, or relay display streams across remote cloud servers.

03 System Requirements & Drivers

Optimal performance requires meeting the following system conditions:

  • Windows Host: Windows 10 or Windows 11 (64-bit). DirectX 11.1+ DXGI Desktop Duplication support is required for screen capture.
  • Extended Display Mode: To establish a genuine independent secondary workspace, the bundled Microsoft IddCx Indirect Display Driver must be installed and active. Desktop Mirroring functions immediately without drivers.
  • Android Client: Android 8.0 (Oreo, API 26) or later with hardware H.264 MediaCodec support.
  • Network Configuration: You are responsible for ensuring your local Wi-Fi router or Windows Defender Firewall permits incoming TCP traffic on port 52025 and UDP discovery on port 52026.
